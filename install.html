installation

Get parAdots running.

parAdots runs entirely on your own machine — no cloud service, no database to host. You need Python 3.10+ and Google Chrome. The package ships with one-click launchers, so the command line is optional.

quick start · one click

The recommended way

  1. Download the package and unzip it.
  2. Double-click parAdots.command (macOS) or parAdots.bat (Windows).
  3. The first start installs everything automatically and opens the dashboard at http://localhost:8765. Every later start opens straight away.

First-launch security note

On macOS, right-click parAdots.command → Open once to get past Gatekeeper. On Windows, if SmartScreen warns, choose More info → Run anyway.

manual setup · all platforms

For the command line

Prerequisites

  • Python 3.10 or newer
  • Google Chrome (used for session-based authentication)
  • Network access to your Pardot and Salesforce environments
  • For Salesforce: the Salesforce CLI logged in, or an active browser session

Setup — identical on Mac and Windows

  1. Download or clone the parAdots repository.
  2. Install the Python dependencies.pip install -r requirements.txt
  3. Install the browser Playwright uses.playwright install chromium
  4. Copy the config template to configs/your-org.env and fill in your credentials.
  5. Select the org you want to audit.python set_org.py --org your-org
  6. Run the audit (add --no-sf to skip Salesforce).python run_all.py
  7. Open the viewer, then browse to http://localhost:8765.python viewer.py
macOS
Install Python via Homebrew (brew install python@3.13) or from python.org. Create and activate the virtual environment with python3 -m venv .venv and source .venv/bin/activate.
Windows
Install Python from python.org (tick "Add Python to PATH") or via winget. In PowerShell, activate the venv with .venv\Scripts\Activate.ps1. Make sure Chrome is installed.
