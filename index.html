how it works

four layers, one command.

Each layer writes clean, org-scoped data the next one reads. Run the whole chain with run_all.py, or any single step on its own.

01 / collect

collect

30+ scrapers pull Pardot config over the v5 REST API and a real browser session, and Salesforce over REST / SOQL — no connected app, MFA-safe.

02 / enrich

enrich

Every asset and program gets a plain-language, AI-generated description of what it actually does — deterministic, so the same input always reads the same way.

03 / analyze

analyze

A cross-reference engine maps every dependency and finds orphans; 14 checks score the setup against best practice and GDPR consent rules; process discovery reconstructs whole flows.

04 / visualize

visualize

An interactive viewer, editable draw.io diagrams and a severity-ranked report turn the data into something you can zoom, export and talk about.

where it earns its keep

three moments in a consultant's week.

parAdots was built around the jobs that eat the most time and carry the most risk.

01 — analysing a new org

From blind spot to full map on day one.

You inherit an org you have never seen. Someone built it over five years and documented none of it; the real architecture lives across a thousand screens.

what parAdots doesOne run inventories every asset, builds the dependency map, flags orphaned lists and broken personalization, and scores the whole setup against 14 best-practice and consent checks.

Walk in blind on Monday, present a findings-backed picture of the org by end of day one.

02 — working with existing orgs

Keep every org honest over time.

Live orgs drift. Paused automations pile up, fields get retired out from under dynamic content, and prospect-sync errors accumulate quietly in the background.

what parAdots doesFrom one cockpit you re-run any scraper, diff against the last audit, resolve sync errors, and trigger enrichment, the cross-reference map or the gap report — the same way for every client org you manage.

Stay on top of every client org without living inside its admin screens.

03 — discussing new processes

A picture the customer can actually read.

Designing a new opt-in, re-engagement or nurture flow with a client means everyone in the room picturing something slightly different — and no one quite sure what already exists.

what parAdots doesEvery Engagement Studio program renders as a clean, collapsible flowchart — decisions, waits, actions and end states laid out exactly as they run, over the assets that are actually live.

The conversation is about the process, not about decoding Pardot.
